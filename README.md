# AWS Multi-Tier Student Management System

## Project Overview
Designed and deployed a secure multi-tier web application on AWS using EC2, Amazon RDS, and VPC.

## Features
- Multi-tier architecture
- EC2 instance hosting
- Amazon RDS (MySQL)
- Custom VPC networking
- Security Groups
- Secure database connectivity

## Technologies Used
- AWS EC2
- Amazon RDS
- Amazon VPC
- Linux
- MySQL
